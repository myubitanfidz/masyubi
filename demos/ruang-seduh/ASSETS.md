# Aset Ruang Seduh

## Ilustrasi produk

Gambar dibuat dengan ImageGen untuk brand kopi fiktif Ruang Seduh, lalu disimpan lokal sebagai WebP. Gambar digunakan sebagai ilustrasi konsep produk dan ritual seduh pada preview.

File dan asal aset (di `assets/images/`):

- `hero-final-640.webp`, `hero-final-960.webp`, dan `hero-final-1440.webp`: ilustrasi kemasan kopi dan cangkir untuk hero.
- `story-640.webp`, `story-960.webp`, dan `story-1440.webp`: ilustrasi kegiatan menuang air ke dripper untuk bagian cerita.
- `jeda-pagi-320.webp` dan `jeda-pagi-640.webp`: ilustrasi katalog jeda-pagi.
- `gayo-senja-320.webp` dan `gayo-senja-640.webp`: ilustrasi katalog gayo-senja.
- `kintamani-320.webp` dan `kintamani-640.webp`: ilustrasi katalog kintamani.
- `flores-320.webp` dan `flores-640.webp`: ilustrasi katalog flores.
- `toraja-320.webp` dan `toraja-640.webp`: ilustrasi katalog toraja.
- `drip-pagi-320.webp` dan `drip-pagi-640.webp`: ilustrasi katalog drip-pagi.
- `drip-gayo-320.webp` dan `drip-gayo-640.webp`: ilustrasi katalog drip-gayo.
- `drip-kintamani-320.webp` dan `drip-kintamani-640.webp`: ilustrasi katalog drip-kintamani.
- `dripper-320.webp` dan `dripper-640.webp`: ilustrasi katalog dripper.
- `server-320.webp` dan `server-640.webp`: ilustrasi katalog server.
- `filter-320.webp` dan `filter-640.webp`: ilustrasi katalog filter.
- `mug-320.webp` dan `mug-640.webp`: ilustrasi katalog mug.

Varian 320/640 px digunakan untuk katalog, sedangkan 640/960/1440 px digunakan untuk hero dan cerita. Halaman menggunakan srcset untuk memilih ukuran gambar sesuai ruang tampilan. Brand, produk, dan profil rasa adalah contoh fiktif untuk portofolio Masyubi.

## Identitas

`assets/mark.svg` adalah simbol identitas lokal Ruang Seduh. Wordmark berupa teks; ikon antarmuka menggunakan SVG inline.

## Font

Plus Jakarta Sans (400-700) dan Lora (400-500) menggunakan file WOFF2 lokal dari Google Fonts. `assets/style.css` memuat keduanya dengan font-display swap.

File dan lisensi lokal:

- `assets/fonts/jakarta.woff2`: Plus Jakarta Sans; salinan lisensi tersedia di `assets/fonts/jakarta-OFL.txt`.
- `assets/fonts/lora.woff2`: Lora; salinan lisensi tersedia di `assets/fonts/lora-OFL.txt`.

Kedua font disertai lisensi SIL Open Font License. Website tidak mengunduh font dari layanan eksternal.
