# Aset SMA Nusa Cendekia

## Galeri ilustrasi

Foto disimpan lokal sebagai WebP pada 8 Oktober 2026. Semua digunakan sebagai ilustrasi konsep; bukan foto SMA Nusa Cendekia, bukti fasilitas, atau klaim dukungan orang yang tampak di foto.

[Unsplash License](https://unsplash.com/license) mengizinkan unduhan, modifikasi, dan pemakaian termasuk komersial. Jangan menyiratkan bahwa subjek foto mendukung sekolah fiktif ini. Tidak menggunakan logo atau foto milik sekolah nyata.

File dan sumber tetap:

- `assets/images/perpustakaan.webp`: [Students studying together at a long table — Jaykumar Bherwani](https://unsplash.com/photos/students-studying-together-at-a-long-table-Dg8WzlOE1as). Halaman sumber menyatakan Free to use under the Unsplash License. [CDN asli](https://images.unsplash.com/photo-1762512346988-045f4d5ad2b3). Hero, 1440px. Foto perpustakaan di Kanada, bukan lokasi sekolah fiktif.
- `assets/images/perpustakaan-720.webp`: Sumber yang sama, 720px; hero mobile dan thumbnail indeks portofolio.
- `assets/images/belajar.webp`: [Sumber CDN Unsplash](https://images.unsplash.com/photo-1522071820081-009f0129c71c). Kelompok di meja dengan laptop; ilustrasi diskusi, 1440px. Tidak diberi label sebagai siswa sekolah nyata.
- `assets/images/laboratorium.webp`: [Sumber CDN Unsplash](https://images.unsplash.com/photo-1532094349884-543bc11b234d). Peralatan gelas laboratorium, 800px; ilustrasi ruang eksperimen.
- `assets/images/seni.webp`: [Sumber CDN Unsplash](https://images.unsplash.com/photo-1513364776144-60967b0f800f). Kuas dan cat, 800px; ilustrasi eksplorasi seni.
- `assets/images/olahraga.webp`: [Sumber CDN Unsplash](https://images.unsplash.com/photo-1546519638-68e109498ffc). Bola dan ring basket, 800px; ilustrasi olahraga.

Parameter unduhan: `w=1440` / `720` / `800`, `q=78–82`, `fit=crop`, `fm=webp`. Crop tampilan memakai object-fit tanpa mengubah file asli. Sumber tidak dimuat dari jaringan saat pengunjung membuka demo.

## Identitas

`assets/images/mark.svg` dan simbol buku inline dibuat khusus untuk demo. Tidak memakai logo sekolah nyata.

## Font

Arial dan Georgia menggunakan font sistem beserta fallback. Tidak ada file font atau permintaan layanan font eksternal.
