# Aset Lajur

## Ilustrasi dashboard

`preview.svg` adalah ilustrasi dashboard berukuran 960 x 600 px untuk kartu preview pada halaman utama Masyubi. File memuat ringkasan bisnis, grafik pesanan, dan tabel data dalam SVG lokal.

Grafik dan ikon pada halaman dashboard dirender dengan SVG inline, HTML, dan CSS. Data bisnis dan pesanan merupakan contoh demo yang disimpan di `app.js`.

File dan asal aset:

- `preview.svg`: ilustrasi preview khusus demo Lajur.
- `mark.svg`: simbol identitas Lajur, digunakan pada navigasi dan favicon.

## Identitas

Wordmark Lajur berupa teks dan simbol lokal `mark.svg`.

## Font

CSS menggunakan urutan font Inter, Segoe UI, Arial, dan sans-serif. Tidak ada file font lokal atau unduhan font eksternal; browser memakai font yang tersedia di perangkat.
